# SoulScope — статистика Deadlock

Сайт: **https://soulscope.pro**

Фанатский трекер Deadlock: тир-лист, билды, контр-предметы, патч-трекер и связки на линии.
Дизайн вдохновлён dota2protracker.com, палитра — тёмная с кремовыми и латунными акцентами в духе Deadlock (есть светлая «пергаментная» тема и бирюзовая тема «Души» — в цвет сфер душ). Кнопка RU/EN в шапке переключает язык всего сайта.

## Запуск

Сайт статический, сборка не нужна. Нужен любой локальный HTTP-сервер (ES-модули не работают через `file://`):

```bash
npm start
```

Потом откройте http://localhost:5173.

## Вкладки

| Вкладка | Что делает | Откуда данные |
|---|---|---|
| **Главная** | Сводка меты по ролям, текущий патч, топ связок | `hero-stats`, `hero-synergy-stats`, патчи |
| **Тир-лист** | Тиры S+…D, сортируемая таблица: WR, Δ WR к прошлому периоду, пикрейт, KDA, урон, души | `/v1/analytics/hero-stats` (текущее и предыдущее окно) |
| **Герои и билды** | Карточки героев → страница героя: **сила по ходу матча** (винрейт по длительности матча против типичного героя + вердикт «ранний / лейт / пик в мидгейме / ровный»), билд по фазам (старт/ранняя/мид/поздняя), ситуативные предметы, «ловушки», порядок прокачки, матчапы, способности | `hero-stats` по 7 интервалам длительности, `item-stats?hero_id`, `ability-order-stats`, `hero-counter-stats`, `hero-synergy-stats` |
| **Контр-предметы** | Выбираете до 6 врагов (и себя) → профиль угроз состава, контр-предметы с объяснениями, предметы по статистике | `item-stats?enemy_hero_ids=…` против базового `item-stats` + профили угроз из `js/knowledge.js` |
| **Патч-трекер** | Патчи из Steam, по каждому герою: бафф/нерф/смешанно, краткий вывод, каждая правка с ▲/▼ и WR за 7 дней до и после патча | `/v2/patches` + `hero-stats` по окнам |
| **Связки на линии** | Пары союзников на одной линии: WR, синергия (WR пары минус средний WR двух героев), фильтр по герою, худшие пары | `hero-synergy-stats?same_lane_filter=true` |
| **Карта** | Теплокарта смертей и драк на выбранном ранге: слои «Смерти», «Драки», «Риск» (где проигрывают стычки чаще, чем на соседних маршрутах), фильтр по фазе матча, 5 самых опасных точек. Обе команды сведены к виду «ваша база снизу» (карта симметрична при повороте на 180°) | `/v1/analytics/kill-death-stats` + миникарта `/v1/assets/map` |
| **Ранги** | Доля игроков на каждом ранге и делении (I–VI), график по 66 подрангам, калькулятор «вы выше X% игроков», порог топ-1%, медианный ранг, конец сезона | `/v1/players/rank/distribution` + ранги и сезоны из `data/assets.json` |

Фильтры **ранг** (Emissary+ … Eternus) и **период** (текущий патч / 7 / 14 / 30 дней) действуют на всех вкладках со статистикой.
Состав во вкладке контр-предметов сохраняется в ссылке (`#/counters?e=13,84&me=3`), такой ссылкой можно поделиться.

## Как сайт обновляется сам

- **Статистика и патчи** запрашиваются из [Deadlock API](https://deadlock-api.com) прямо в браузере и кэшируются на 20–30 минут. Новый патч появляется в трекере автоматически, как только Valve опубликует его в Steam, и сразу разбирается по героям.
- **Имена, иконки и способности** лежат в `data/assets.json` (снапшот, ~250 КБ, RU + EN). Если в статистике появился герой, которого нет в снапшоте (новые герои сейчас выходят дважды в неделю), сайт догрузит его из API на лету. Чтобы обновить снапшот целиком (новые способности, предметы):

```bash
npm run update-assets
```

## Как считается

- **Рейтинг / тир.** Винрейт сглаживается к 50% по объёму выборки (байесовски, K=250), потом рейтинг = 50 + 15·(0.8·z(винрейт) + 0.2·z(log пикрейта)), обрезанный до 1–99. Тиры: S+ ≥75, S ≥63, A ≥53, B ≥43, C ≥33, иначе D.
- **Билд по фазам.** Фаза определяется по среднему времени покупки предмета. Основной билд — самые покупаемые предметы фазы.
- **Ситуативные предметы и ловушки.** Винрейт предмета сравнивается со средним винрейтом предметов той же фазы. Иначе поздние предметы выглядели бы «имбой» просто потому, что их чаще покупает выигрывающая команда.
- **Контр-предметы.** Для каждого врага: винрейт предмета против него минус винрейт предмета в целом, минус общий сдвиг винрейта против этого героя (против сильного героя проседают все предметы). Результат усредняется по выбранным врагам.
- **Бафф или нерф в патче.** Каждая строка вида «X increased/reduced from A to B» разбирается по числам. Для параметров, где «меньше — лучше» (перезарядка, стоимость, задержка каста и т. п.), направление инвертируется. Вердикт по герою считается по соотношению усилений и ослаблений. Реальный эффект показывает Δ винрейта до и после патча.

## Структура

```
index.html            каркас, шапка, навигация
css/style.css         темы (тёмная, кремовая, «Души»), все компоненты, адаптив
js/app.js             роутинг по hash, поиск Ctrl+K, темы, язык интерфейса RU/EN (перевод — функция L() из core.js)
js/api.js             клиент Deadlock API с кэшем
js/core.js            состояние фильтров, ассеты, расчёт меты и тиров, HTML-компоненты
js/patches.js         загрузка и разбор патчноутов
js/knowledge.js       роли, профили угроз героев, контр-предметы, словарь для патчноутов
js/views/*.js         вкладки
scripts/update-assets.mjs  снапшот ассетов
data/assets.json      снапшот ассетов
```
